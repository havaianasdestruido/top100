How this list is built

A single GitHub Search API request per language — ?q=language:ruby&sort=stars&order=desc&per_page=100 — refreshed hourly by a scheduled GitHub Actions workflow and committed back to the repository. The records are never reshaped: every field GitHub returned is preserved. The methodology page covers the query, the rate limits, the fields the Search API omits and the known limitations, and the field reference documents every JSON key.
